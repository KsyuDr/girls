# Безопасный город — монорепозиторий

Перед любой задачей прочитайте `agents/README.md` и файлы, на которые он ссылается:
там концепция продукта, принятые решения, архитектура, модель данных, API-контракт,
этапы разработки и соглашения по стилю/коммитам/тестам.

- `backend/` — FastAPI (Python 3.13, uv). Тесты: `cd backend && uv run pytest -q`
  (нужен `docker compose up -d db`).
- `frontend/` — React + Vite. Линт: `npm run lint`, формат: `npm run format`.
- После каждого этапа: тесты + проверка в браузере + обновить `agents/06-roadmap.md`.
