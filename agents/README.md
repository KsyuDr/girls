# agents/ — решения и контекст проекта

Эта папка — «память» проекта для людей и ИИ-агентов (Claude Code и др.).
Перед любой задачей в репозитории прочитайте файлы по порядку. Если решение меняется,
обновите соответствующий файл в том же коммите, что и код.

| Файл | О чём |
|---|---|
| [01-product.md](01-product.md) | Что за продукт, концепция «люди помогают людям», роли, чего НЕ делаем |
| [02-decisions.md](02-decisions.md) | Журнал принятых решений (кратко: что решили и почему) |
| [03-architecture.md](03-architecture.md) | Стек, структура репозитория и бэкенда, договорённости по API |
| [04-data-model.md](04-data-model.md) | Модель данных (таблицы, поля, статусы) |
| [05-api-contract.md](05-api-contract.md) | Эндпоинты и как они стыкуются с `frontend/src/services/api.js` |
| [06-roadmap.md](06-roadmap.md) | Этапы разработки, статус, критерии готовности этапа |
| [07-conventions.md](07-conventions.md) | Стиль кода, линтеры, коммиты, тесты, как запускать |
| [08-review.md](08-review.md) | Ревью и тестирование MVP: найденные ошибки, гонки, что исправить первым |

## Источники контекста
- Лабораторные 1–4 по дисциплине «Управление программными проектами» (анализ ЦА, конкуренты,
  выбор модели ЖЦ — **инкрементная**, план задач по часам). Лабы — аналитика, кода в них нет.
- Дизайн: Figma-файл «Полина», страница «Безопасный город» (9 desktop + 9 mobile экранов).
- Фронтенд: `frontend/` (React 19 + Vite), сверстан по макетам 1-в-1, пока на моках.
